# SRH Profile Recommender 0.1.0-alpha.1

First alpha of the SRH workload-driven runtime decision layer.

## Included

- Workload contracts and experimental planning.
- Paired probe/assistant measurements and observed runtime fingerprints.
- Raw sample validation, structured answer replay and quality/SLO gates.
- Deterministic selection of eligible configurations or an explicit refusal to recommend.
- Decision evidence in JSON and Markdown, with scope and suggested next experiment.
- Controlled Docker campaign for prefill budgets 8192, 4096 and 16384, preserving and restoring the original runtime.
- SRH-focused documentation, full Apache-2.0 license and retained upstream attributions.

## Validation

The original functional suite contains 14 passing offline tests. Additional tests
cover release preflight and recovery from partially completed publishing steps.
Live evidence covers one model/runtime family on GB10, a synthetic enterprise-orders
scenario, five repetitions per response mode, and three runtime configurations.

Assistant TTFA p95 was 5.55, 5.95 and 6.01 seconds respectively. All profiles passed
structured quality at 100% and failed the 2-second TTFA p95 target. A later shared-prefix
control measured 1.43 seconds median / 2.62 seconds p95, still failing that target.
The result is exploratory and does not demonstrate statistical tail confidence.

## Scope and limitations

- Same-model configuration comparison; cross-model ranking is not yet implemented.
- Docker/vLLM acquisition and a structured enterprise-orders evaluator.
- No model weights or container image are distributed as release assets.
- External model/runtime licensing remains separate from SRH source licensing.
- No claims of general AI quality certification, cost savings or model superiority.

The repository retains blazux runtime integration. See README.upstream.md and
THIRD_PARTY_NOTICES.md for attribution and distribution boundaries.
