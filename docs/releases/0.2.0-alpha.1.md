# SRH Profile Recommender 0.2.0-alpha.1 — draft

This release candidate adds the workload-to-candidate capacity layer required before
measured profile recommendation.

## Included

- Client-meeting web interface served locally with no external dependencies.
- Business-readable client intake and versioned schema.
- Workload Contract translation with traceable token assumptions.
- Starter hardware catalog for GB10, RTX PRO 6000 Blackwell and H100 SXM.
- Generic model sizing archetypes independent of named checkpoints.
- Deterministic memory, context and power screening.
- Low-confidence performance bands and explicit evidence provenance.
- Hardware-diverse candidate shortlist and benchmark handoff.
- JSON and Markdown capacity dossiers.
- Deployment Recommender for comparable observed candidates across hardware/models.
- Mandatory human-supplied license review and traceable three-year cost metadata.

## Decision boundary

Capacity results are preliminary. Quality is not simulated. Estimates cannot be fed
to the measured Profile Recommender as if they were observed evidence. Exact models,
runtime profiles, licensing and the client scenario must be resolved and benchmarked
before a deployment recommendation.
